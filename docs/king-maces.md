# King mace names

Mace of King (group 2, item 22) and Royal Mace of King (group 2, item 23)
use orange name text in inventory tooltips and ground labels. Other item names
and the colors of stats, requirements and option descriptions are unchanged.
Excellent/ancient prefixes and option text remain visible where applicable.

Both item entries and model registrations use the supplied macedemonc.bmd
and celesmace.bmd unchanged. Textures in Item/KingMaces/Normal and Royal are
temporary copies of existing mace textures, not the missing original skins.
Replace those temporary texture files with the original matching texture names
when available. Model assignments: macedemonc is Mace of King; celesmace is Royal.

Weapon tooltips use +4 minimum and maximum damage per upgrade level, matching
the server. Requirements and base stats match the staged server definitions.
Ordinary weapon upgrade calculations and colors are unchanged.
